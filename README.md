Python Case Studies Collection --- README
Author: Radhasahithi Challa
Overview
This repository contains ten Python case studies prepared for learning
and demonstrating core programming concepts. The programs use input
validation, variables, arithmetic operations, conditional statements,
loops, lists, tuples, sorting, and report generation.
Projects Included
1. Food Waste Monitoring System
Tracks meals prepared and served across multiple days, calculates
leftovers and daily/overall wastage percentages, and flags days when
food waste exceeds the acceptable limit.

Key concepts: loops, validation, arithmetic, percentages,
conditional reporting.
2. Bus Passenger Occupancy Simulation
Simulates passengers boarding and alighting at multiple bus stops. It
tracks current occupancy, validates alighting counts, checks bus
capacity, and reports capacity violations.

Key concepts: loops, counters, validation, conditional statements.
3. Campus Event Financial Feasibility
Calculates event costs, registration income, sponsorship, financial
surplus or shortfall, and the minimum number of registrations required
to break even.

Key concepts: financial calculations, input validation,
conditionals, while loops.
4. Hospital Billing and Patient Classification
Calculates a patient's bill from consultation, diagnostic, and treatment
charges. It applies the example age-based concession, calculates the
balance due, and classifies payment as Paid in Full, Partially Paid, or
Payment Pending.

Key concepts: arithmetic, age-based conditions, validation,
classification.

Note: The concession rates in the case study are educational
examples, not official hospital tariffs.
5. Hackathon Team Formation and Ranking
Records teams and their round scores, calculates total scores, validates
team data, and ranks teams using the case study's tie-breaking rules.

Key concepts: lists and dictionaries, loops, sorting, validation,
ranking logic.
6. Mobile Recharge Plan Cost Calculator
Compares Basic, Standard, and Premium mobile plans using a user's usage
requirements and budget, then identifies suitable plans and the
lowest-cost qualifying option.

Key concepts: conditions, arithmetic, comparison, filtering, input
validation.
7. Student Feedback Sentiment Scoring
Processes student feedback using the case study's sentiment-scoring
rules and produces a score or classification for the feedback.

Key concepts: strings, text processing, counting, conditionals,
summaries.
8. Library Borrowing and Fine Reconciliation
Processes book borrowing records, calculates fines for overdue returns,
identifies overdue records, and marks books as Available or Borrowed.

Key concepts: tuples, record validation, loops, calculations,
reconciliation.
9. Railway Fare and Reservation Calculator
Calculates fares for multiple passengers using distance slabs and travel
classes. It includes age-based concessions, reservation fees,
cancellation penalties, and refund calculations according to the case
study's rules.

Key concepts: input validation, loops, arithmetic, conditions,
passenger-wise reports.

Note: Fare slabs, fees, concessions, and penalties are the
assumptions specified for this educational program; they should not be
treated as current official railway tariffs.
10. Sports Tournament Ranking System
Records match results and calculates team points, wins, draws, losses,
goals for and against, goal difference, and final rankings according to
the stated tie-break rules.

Key concepts: dictionaries, loops, match statistics, sorting,
ranking.
Requirements
- Python 3.x
- No third-party libraries are required for the core console programs
  unless a particular source file explicitly states otherwise.
- A terminal or command prompt to run the scripts.
How to Run
1. Save or locate the Python source file for the project you want to
   run.
2. Open a terminal or command prompt in that file's folder.
3. Run the script with Python. For example:
   python food_waste_monitoring.py
4. Follow the prompts and enter valid values.
Replace food_waste_monitoring.py with the actual filename of the
project you are running.
General Validation and Assumptions
- Enter numbers where numeric input is requested.
- Negative values, impossible counts, duplicate identifiers, or
  invalid selections should be handled according to each case study's
  rules.
- Sample rates, thresholds, fares, concessions, fines, and tie-break
  rules are educational assumptions defined in the individual case
  studies.
- These are console-based learning projects and do not connect to live
  hospital, library, railway, bus, mobile-network, or tournament
  systems.
Learning Outcomes
By completing these case studies, students can practise:
- Reading and validating user input.
- Using variables and appropriate data structures.
- Applying arithmetic formulas and percentage calculations.
- Using if, elif, and else for decisions.
- Repeating operations with for and while loops.
- Processing records and maintaining running totals.
- Sorting and ranking results using defined rules.
- Producing clear summaries and reports.
- Testing normal, boundary, and invalid input cases.
Suggested Testing
For each program, test: 1. A normal valid input. 2. Minimum and maximum
or boundary values. 3. Invalid or negative input where applicable. 4.
Cases that trigger each major condition or classification. 5. Multiple
records to confirm that totals and summaries are correct.
Conclusion
This collection brings together ten practical Python case studies
covering food-waste tracking, passenger occupancy, event finance,
hospital billing, team ranking, recharge plans, feedback scoring,
library fines, railway fares, and sports tournament results. Together,
they demonstrate how fundamental Python concepts can be applied to
structured, real-world-style problems.
